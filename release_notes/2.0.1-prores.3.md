# Vibeshine 2.0.1-prores.3

Experimental ChloroFrame ProRes build: Vibeshine 2.0.1 plus a GPU ProRes encoder for local-network streaming. Not an official release.

## Changes

- Added a D3D11 compute ProRes encoder (10-bit 4:2:2 and 4:4:4, SDR and HDR10) that runs through the intra-only PyroWave session loop and transport. It is advertised only to clients that ask for it.
- Fixed: ProRes sessions failed with "invalid negotiated frame rate, bitrate or packet size" because the negotiated packet size was never copied into the encoder config.
